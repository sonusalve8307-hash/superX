# FraudShield AI

## AI-Powered Fraud Detection & Cybersecurity Platform

FraudShield AI is a Java-based cybersecurity platform designed to detect
fraudulent activities, analyze transaction risks, and provide intelligent
security protection.

## Technologies

- Java
- JavaFX
- Firebase / Firestore
- Maven
- AI / Machine Learning

## Project Features

- AI Fraud Risk Analysis
- Transaction Monitoring
- AI Phishing Detection
- Security Alerts
- User Authentication
- Role-Based Access Control
- AI Security Analysis
- Admin Dashboard

## Team

This project is developed by a team of 5 members as part of the
Java SuperX project.
